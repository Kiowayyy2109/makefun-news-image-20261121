The World in One Page — 21 November 2026: a program that draws the day's world news as a one-page newspaper front page. Lead story: Russian missiles land in Poland and NATO calls it a grave violation. Also inside: Wall Street slumps into correction as AI shares plunge, the World Court finds Myanmar committed genocide against the Rohingya, the UK and EU sign new deals, the first Trump–Xi–Putin summit ends with little to show, COP31 talks deadlock, and Cyclone Akvan slams India's east coast. Every story was reported 20–21 November 2026 (AP, Reuters, BBC, CNN, Le Monde). The program draws the image procedurally with Pillow (bundled DejaVu fonts, no network, fully deterministic) and falls back to the bundled `artwork.png` when Pillow is unavailable.

## Run it

```sh
python3 main.py
```
